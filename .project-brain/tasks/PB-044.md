# PB-044 — Hesap/istatistik düzeltmesi: taban çizgisi, pro-rata, kalibrasyon

## Status
IN_PROGRESS

## Dependencies
None

## Affected Areas
record_repository.dart, progress_index.dart, module_providers.dart, body_load_model.dart, nicotine_model.dart, economy.dart, onboarding.dart

## Objective / Spec
(1) avoided/savings yalnız TAMAMLANMIŞ günler, BASELINE'a göre; bugün pro-rata/'devam ediyor'. (2) Beyanlı taban çizgisi (adet+aralık), tutarsızsa çelişki diyaloğu. (3) Puan >=3 tamamlanmış gün; öncesi 'Kalibrasyon N/3'. (4) Bedava puanlar kalkar. (5) Burst: ardışık girişler nikotin yükünde doğru. (6) Nikotin/CO % referansı = beyan düzeninin steady-state tepe değeri; ölçek+kaynak ekranda. (7) 24 saat grafiği: beyan (gri) vs gerçek (renkli). (8) Psikolojik durum kartı kaldır/kayda dayandır.

## Acceptance Criteria / Verification
Regresyon: 17 hedef + 4 ardışık sigara => tasarruf 0 TL, puan yok ('Kalibrasyon'); 20/gün + 'yarım saatte bir' => çelişki uyarısı; 3 tamamlanmış gün sonrası puan hesaplanır.
